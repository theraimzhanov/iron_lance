# Iron Lance

A browser jousting game (Babylon.js). Prototype stage: one player against a bot, three passes, in a tournament
arena with a castle, crowd and full sound.

## Play

```bash
python -m http.server 8080
```

Open http://localhost:8080 and press **W** to charge.
For the dusk "Bloodfall" arena (shorter 48 m lists, heavier to render), open http://localhost:8080/?arena=bloodfall.

| Control | Action |
|---|---|
| W / ↑, S / ↓ | Spur / rein in the horse |
| Mouse | Aim the lance |
| Space / right-click | Raise the shield (max 1.2 s; your lance wobbles while it's up) |
| R | Rematch |
| M | Sound on/off |

**Scoring:** shield hit +1, body hit +2, guard turns body hits into shield hits. A centred hit at ≥ 36 km/h
breaks the lance (+1). A dead-centre unguarded body hit at ≥ 41 km/h unhorses the rider: instant win.
Tuning constants are at the top of `index.html`.

## Assets

- `assets/sketchfab/horse/` is the Sketchfab glTF download **exactly as downloaded**. Its licence (CC BY-ND) forbids
  distributing a modified copy, so never edit or re-export it; the game only hides its ground disc at runtime.
- `assets/rider.glb` is the Sketchfab knight posed for riding. Download "Armored Guard Knight Rig" as glTF, then:

Everything else in `assets/` is generated by scripts. Blender 5.3 runs headless:

```bash
blender -b -P scripts/blender/build_rider.py -- <knight>/scene.gltf assets/rider.glb [preview_dir]
python scripts/fetch_props.py <staging_dir>                               # download Poly Haven props
blender -b -P scripts/blender/pack_props.py -- <staging_dir> assets/props
blender -b -P scripts/blender/assemble_castle.py -- <staging_dir>/modular_fort_01 assets/props
```
